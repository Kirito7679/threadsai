🧵 Подключите аккаунт Threads

Осталось два шага, дальше платформа работает сама.

1. Приложение Threads

На developers.facebook.com создайте приложение с сценарием использования «Threads API» и включите разрешения: threads_basic, threads_content_publish, threads_manage_insights, threads_manage_replies, threads_keyword_search.

В настройках приложения укажите Redirect Callback URL — он должен точно совпадать со значением THREADS_REDIRECT_URI:

{{ app_settings.threads_redirect_uri }}

Аккаунт Threads должен быть публичным и переведён в профессиональный режим, иначе API не выдаст разрешения.

2. Авторизация

Нажмите кнопку — откроется страница Threads, где вы подтвердите доступ. Токен сохранится в базе в зашифрованном виде и будет продлеваться автоматически.

Политика конфиденциальности

Threads Autopilot — персональный инструмент автоматизации Threads.

Какие данные обрабатываются

  • Токен доступа Threads, выданный вами через официальную авторизацию Meta.
  • Публичные данные вашего профиля: идентификатор, имя пользователя, аватар.
  • Ваши публикации и их статистика: просмотры, лайки, ответы, репосты, цитаты.
  • Публичные посты других авторов, найденные официальным поиском Threads по ключевым словам — используются только для анализа тем и форматов.
  • Настройки, которые вы задаёте сами: ниша, тон голоса, расписание публикаций.

Логин и пароль от Threads приложение не получает и не хранит: вход происходит на стороне Meta, обратно возвращается только токен доступа.

Как данные хранятся

Данные лежат в базе на сервере владельца приложения. Токен доступа хранится в зашифрованном виде (алгоритм Fernet, AES-128 в режиме CBC с HMAC-подписью). Доступ к панели возможен только после авторизации в Threads под аккаунтом, которому эта панель принадлежит.

Кому передаются данные

Данные не продаются и не передаются третьим лицам. Тексты публикаций и выдержки из собранных постов отправляются в сервис DeepSeek для генерации черновиков — это необходимая часть работы приложения. Публикация в Threads выполняется через официальный Threads API компании Meta.

Удаление данных

Вы можете отозвать доступ приложению в настройках Threads в любой момент — после этого приложение теряет возможность читать и публиковать что-либо. Чтобы удалить накопленные данные, воспользуйтесь страницей удаления данных.

Контакт

По вопросам обработки данных пишите владельцу приложения на почту, указанную в карточке приложения в кабинете Meta.
